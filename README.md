# Seabird plastic ingestion analyses

Analysis code for examining the effects and long-term patterns of plastic ingestion in seabirds. The work combines evidence from the long-term monitoring programme with data from individual studies and publications. These study datasets have their own sampling designs and are analysed as distinct sources; they are not treated as one continuous dataset.

## Research question

1. **Physiological responses:** How does plastic ingestion relate to measured physiological outcomes? Dose–response relationships are modelled for individual outcomes, outcome-specific exposure thresholds are estimated, and estimates are synthesised across physiological systems using a meta-analytic framework.


## Repository contents

This repository contains the analysis scripts and supporting materials for the analyses above. The exact script and input-data layout may vary by analysis component. See comments at the top of each script for its purpose, required inputs, and output files.

## Data

Data availability and reuse conditions may differ among sources, please refer to the initial publication for accessibility. We have provided an example Linear (albumin) and 4PL (pdgfrb) data to run the code. 

## Running the analyses

1. Clone or download this repository.
2. Obtain the required data using the sources and access conditions documented for each analysis.
3. Open the relevant script and update any input and output paths for your computer.
4. Run the scripts in the order indicated in their comments. Outputs are written to the locations specified in each script.

The code is provided to document and reproduce the analyses. Exact results may depend on the data versions and software package versions used; record these when reproducing the work.
